Per-Item Encryption

Each item has its own derived key. Compromising one item never exposes others. Unique nonces per operation.

Zero Metadata Leakage

Unlike legacy providers, we encrypt everything: names, URLs, and timestamps. Even our infrastructure cannot profile you.

Memory Safety

Sensitive data wiped from memory immediately after use. unsafe.Pointer barriers prevent compiler elision of zeroing.

HIBP Integration

Opt-in breach detection using k-anonymity. Only the first 5 characters of SHA-1 hash are sent — never your passwords.

Quick start

Up and running in 2 minutes

1

Install

Terminal 
$ go install github.com/zeropass/zp@latest
2

Initialize

Terminal 
$ zp init

Creates encrypted vault & provides your 12-word recovery phrase.

3

Use

Terminal 
$ zp add --type=login --name="GitHub" --generate-password
$ zp get "GitHub" --copy
